What this educational CPU simplifies

  • Instruction set: invented 16-bit, single-instruction ISA. 0x1123 means ADD R1,R2,R3, with one four-bit field per opcode/register. This is not real ARM, x86, or RISC-V machine code.
  • State and timing: fetch is split into address and data microsteps, followed by decode, execute, write-back, and PC advancement. These are conceptual teaching steps, not guaranteed single hardware clock cycles. No pipeline, cache, hazards, branch prediction or bus contention is modeled.
  • Registers: signed 16-bit two's-complement integers; addition wraps modulo 65,536 if it overflows. The ALU computes in Execute, but the register file updates R1 only in Write-back. The instruction occupies two bytes, so the PC changes from 0x0000 to 0x0002 in the final step.
  • Data movement: animated arrows illustrate logical movement or control signaling—not physical electrical traces or clock-accurate waveforms. Students may edit the starting register values, then replay the same instruction.
